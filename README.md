# NeuraFlow AI — AI Technology Website

A simple landing page for a fictional AI startup concept called **NeuraFlow AI**. It was created as a first-year Web Development activity using **HTML5 and CSS3**.

## About the project

The webpage introduces the fictional company and describes example AI services, its approach to technology, and its mission.

## Sections

- Company introduction
- AI solutions / services
- Technology approach
- Mission and about section
- Contact section

## Technologies used

- HTML5 — webpage structure and content
- CSS3 — layout, colors, spacing, and responsive styling

## Files

- `index.html` — main webpage
- `style.css` — styles used by the webpage

## Run locally

1. Download or clone this repository.
2. Keep `index.html` and `style.css` in the same folder.
3. Open `index.html` in a web browser. You can also use the Live Server extension in Visual Studio Code.

## Deployment

This project can be hosted free using GitHub Pages:

1. Upload both files to the root of a GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
4. Open the published URL shown on the Pages settings screen.

## Note

NeuraFlow AI is a fictional startup concept created for this student project. The AI services described are illustrative webpage content, not working AI tools.
